<h1>🏓 Ping Pong Game</h1><br>
A classic Ping Pong game built with NetBeans, featuring multiple game modes and customizable settings.<br>
<br>
<h2>✨ Features</h2><br>
- 🎮 <b>Two Game Modes</b>:<br>
  - Player vs AI (with 3 difficulty levels)<br>
  - Player vs Player (local multiplayer on the same PC)<br>
<br>
- ⚙️ <b>Customizable Settings</b>:<br>
  - Adjustable difficulty<br>
  - Adjustable paddle size<br>
  - Configurable ball speed<br>
  - Points to win selector<br>
  - Volume control<br>
<br>
- 🎨 <b>Clean UI</b> with smooth animations<br>
- 🎶 <b>Sound effects</b> for immersive gameplay<br>
- ⏯️ Pause/resume functionality<br>
<br>
<h2>🛠️ Installation</h2><br>
1. <b>Requirements</b>:<br>
   - Java JDK 11 or later<br>
   - Netbeans IDE 25<br>
<br>
2. <b>Build & Run</b>:<br>
   <code>git clone https://github.com/RayenAkrich/Ping-Pong-Game.git</code><br>
   <code>Open Netbeans</code><br>
   <code>Go to "File"</code><br>
   <code>Click on Open Project</code><br>
   <code>Navigate to your project</code><br>
